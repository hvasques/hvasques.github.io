Five font pairings on the Portfolio screen. The first is the current one, kept only for comparison.

The overline problem. Small uppercase monospace with wide letter-spacing ("SAMPLE · CASE STUDY") is the stock label of generated sites. None of the new pairings use a monospace font. Each one replaces that label with something from its own family: an italic serif, plain sentence case, or condensed capitals. Grades are set in the display face, as a guidebook would print them.
